# Mutation taxonomy

Stage 3 reports the following observed change types:

- `CERTAINTY_ESCALATION` and `CERTAINTY_REDUCTION`
- `URGENCY_ESCALATION` and `URGENCY_REDUCTION`
- `CLAIM_ADDITION` and `CLAIM_REMOVAL`
- `QUALIFIER_REMOVAL`
- `NUMERICAL_MUTATION`
- `ENTITY_MUTATION`
- `TEMPORAL_MUTATION`
- `NEGATION_MUTATION`
- `SEMANTIC_DRIFT`

Each record includes the source and target claims, supporting spans, detection
method, semantic similarity, explanation, and limitations. These are textual
observations, not proof of intent, fraud, or factual falsity.
